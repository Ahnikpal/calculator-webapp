Bootstrap and HTML Calculator
Task:
Created a Calculator using HTML and Bootstrap.
This project demonstrates the use of Bootstrap for styling and layout along with HTML and JavaScript for functionality.

Abstract:
This project focuses on building a functional calculator using HTML for structure, Bootstrap for responsive design, and JavaScript for interactivity. The calculator can perform basic arithmetic operations like addition, subtraction, multiplication, and division, providing a user-friendly interface that is both aesthetic and responsive.

Objective:
To develop a web-based calculator using HTML, Bootstrap, and JavaScript.

To understand the integration of frontend technologies.

To demonstrate the application of Bootstrap classes in layout design.

Introduction:
A calculator is a basic tool used in everyday life. In this project, we create a simple calculator application that can be used directly in a web browser. The project uses HTML for content structure, Bootstrap for styling and responsiveness, and JavaScript to handle the logic behind the operations.

Methodology:
HTML is used to create the layout of the calculator (buttons, display screen, etc.).

Bootstrap is integrated for responsive design and aesthetics using its grid and utility classes.

JavaScript is employed to handle the arithmetic logic and button interactions.

The design ensures the calculator is accessible on both desktop and mobile devices.

Conclusion:
This project successfully demonstrates how to build a responsive and functional calculator using only HTML, Bootstrap, and JavaScript. It strengthens the understanding of DOM manipulation, Bootstrap layout system, and JavaScript logic handling. The calculator can be further extended with features like backspace, decimal input, or scientific functions.
